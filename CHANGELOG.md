# Changelog

The changelog of External Repositories is maintained in a single place: the **`== Changelog ==` section of [`readme.txt`](readme.txt)**. It is the source of truth, and it is what WordPress shows in the plugin's "View details" modal.

Each release is also published on [GitHub Releases](https://github.com/wp-content-io/external-repositories/releases), with its notes taken from `readme.txt` and the `external-repositories.zip` package attached.

Contributors: add a line for user-facing changes to `readme.txt`, not to this file (see [CONTRIBUTING.md](CONTRIBUTING.md#changelog)).
